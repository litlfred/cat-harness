Visualization tools 
Two visualizations were compared. The Dotted Chart in ProM 6.2 (see Section 2.1) was compared to the 
PPMChart (see Section 3.2). Each participant had to work with only one visualization (i.e., either Dotted Chart 
or PPMChart). To prevent interference, one user that was familiar with the Dotted Chart was instructed to use 
the PPMChart. A random visualization was appointed to the other users, but in such a way that each 
visualization in the end would have been tested by an equal amount of users.
