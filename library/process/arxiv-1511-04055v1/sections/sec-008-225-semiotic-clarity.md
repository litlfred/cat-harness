Semiotic clarity 
Semiotic clarity means that every concept is represented by exactly one symbol and every symbol represents 
exactly one concept (Goodman, 1968). 
Every event class of the event log is represented in a Dotted Chart as a dot with a unique color. Moreover, each 
dot has a unique position. Therefore, the Dotted Chart has maximal semiotic clarity. Nevertheless, it can 
sometimes be appropriate to introduce symbol deficit (i.e., use the same symbol for different concepts) to 
increase graphic economy (Moody, 2009).
