ig-annex

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/ig-annex

Annexes an IG's narrative pages load on demand: an `annexes.json` (`ig-annexes/v1`) naming, for each annex, the page it belongs on, the file beside the declaration that holds it, and the columns its table shows before a row is opened. The IG site build (`stage-ig-sites.ts`, and `ig-repo-site.ts compose` for an IG repository's own site) copies each file to `assets/annex/` and mounts `ig-annex.js` on the page. A `.md` annex is appended to its page as written, so its links address that page (`shownOnPublishedPages`); `check:ig-annex-links` judges them from there.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.
