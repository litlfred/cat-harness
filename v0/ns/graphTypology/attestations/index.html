attestations

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/attestations

QA attestations — the judgements a QA family carries across runs (pair attestations, voice reviews, agent and human verdicts, bibliography verifications and human reviews), one `qa-attestations/v1` file per subject, mirroring the derived family's tree. Kept on main where deleting derived results cannot reach them; each entry pins the hash it attested, so a stale one is detectable.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.
