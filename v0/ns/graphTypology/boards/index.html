boards

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/boards

Boards — one JSON file each, carrying `"$schema": "folio-board/v1"`. A board is a diagram OF a folio: it declares what it shows, and a folio with no board is complete. Schema: `schemas/ui/board.ts`.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.
