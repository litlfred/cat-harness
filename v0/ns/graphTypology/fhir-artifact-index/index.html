fhir-artifact-index

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/fhir-artifact-index

The artefact index of a published FHIR Implementation Guide, reconstructed from its published output — every artefact by canonical URL and published representation, with the IG API's JSON Schema / JSON-LD sidecars as an overlay where the IG publishes them. No IG publishes such an index itself, so every field records which file it came out of.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.

A term of the cat-harness vocabulary (https://litlfred.github.io/cat-harness/v0/ns/; machine-readable: index.jsonld).
