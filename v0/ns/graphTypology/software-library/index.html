software-library

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/software-library

Outside libraries a layer imports or vendors -- one generated `software-library` node per library per layer, with the version and sha512 its `bun.lock` pins, its SPDX licence, its range, whether it is a dev dependency, the files that import it and the shim that types it. Shares its core with `tool-release`.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.

A term of the cat-harness vocabulary (https://litlfred.github.io/cat-harness/v0/ns/; machine-readable: index.jsonld).
