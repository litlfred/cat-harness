fhir-core-definitions

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/fhir-core-definitions

The FHIR core specification's definitions for each stable release (R4 4.0.1, R4B 4.3.0, R5 5.0.0), with HL7's publication as the authority: resources, complex and primitive datatypes and the root types, one graph per release keyed by canonical URL (http://hl7.org/fhir/StructureDefinition/<id>). A pins node names HL7's own hl7.fhir.<release>.core package at its hl7.org URL, by sha1 and sha512; a manifest per release lists every definition with HL7's published URL for it, its kind, base and the sha256 of its bytes in HL7's package; a class model per release is the UML derived from that package, which HL7 publishes only as pictures, citing the definition and element of every class and attribute.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.
