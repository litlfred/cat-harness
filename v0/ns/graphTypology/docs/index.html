docs

https://litlfred.github.io/cat-harness/v0/ns/graphTypology/docs

Documentation ABOUT the knowledge graph — how the harness works, what its directories hold, how a process runs. Rendered by the plain just-the-docs pipeline. Distinct from `folio`, which is content an author CREATES using the graph; the difference is the SUBJECT, not the format. An L1 library's catalogue is `library/`; a note about it is a `folio`; the page explaining how ingestion works is `docs`.

Defined by https://litlfred.github.io/cat-harness/v0/ns/.
