Test plans -- one `test-plan/v1` document per plan, in the FHIR R5 TestPlan shape: the system-under-test kind and version range, the `req:` requirements it is evidence for, test cases whose assertions are criterion ids, fixed (reviewed) or generated (template + params + seed) test data, and the certification rule as a DMN reference.
