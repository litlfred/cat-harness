payload

https://litlfred.github.io/cat-harness/v0/ns/payload

Where a node's heavy content is published: an immutable, content-addressed file at `<BASE_URL>/payload/sha256/<hex>`, the hex being the SHA-256 of its bytes. A subgraph file carries this link in place of the body (bean `f233`).

Defined by https://litlfred.github.io/cat-harness/v0/ns/.
