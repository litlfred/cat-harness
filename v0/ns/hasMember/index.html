hasMember

https://litlfred.github.io/cat-harness/v0/ns/hasMember

A node a named subgraph DIRECTLY contains: the deepest subgraph directory holding the node's source path, or its `partOf` parent's subgraph when it has no path. Transitive membership is not a second property — it is this one, followed through `hasSubgraph` (bean `c1m4`).
