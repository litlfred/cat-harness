# merge-reviews

The adversarial review verdict on each pull request's HEAD: `<head sha>.json`, one `merge-review/v1` file per head. Written by a reviewing session that is not the author ([`adversarial-code-review`](https://github.com/litlfred/cat-harness/blob/main/skills/sdlc/sdlc-core/adversarial-code-review.md)) and read by `check:adversarial-review`. Empty until the first review is recorded.
