    ## Why this skill exists

    The single most common churn-inducing antipattern in a results-driven project: an agent probes empirically, finds a numerical near-match, and promotes it to production before the near-match has any derivation. A "5.6 ppm match" found by a search at one parameter value is, much more often than not, a coincidence — not structure. This skill codifies the discipline that short-circuits the propose → flag → restore cycle: escalate up front rather than after review catches it.
