The report answers about the default branch — and Pages is not on it

  • owner-decision 2026-09-20

That is the owner's framing, 2026-09-20, and it settles how the tool must behave: look external, cache nothing. A committed answer would be right when it was written and silently wrong from then on, which is the original defect rebuilt in a new place.

  • bean bean folio-assistant-ey1c
    A green outcome on a derived gate (such as readme:subgraphs:check, docs:harness:check, or other verify/write pairs) must never be read as "was never broken" (bean folio-assistant-ey1c).
  • pr PR #1938 PR #1940 2026-10-03
